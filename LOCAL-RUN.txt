观澜本地运行说明

访问：http://127.0.0.1:3001
后端：http://127.0.0.1:8081/api/health
在此目录运行：
  ./run-local.sh start
  ./run-local.sh status
  ./run-local.sh stop

首次使用请在网页注册自己的账户；模型和交易所需自行配置。
默认中文，可通过页面语言按钮切换。
界面已移除原品牌、推广链接、外部统计和字体；验证器二维码在本地生成。
本地调整：前端 3001、后端 8081；仅监听本机；中文默认语言。

配置：config.json 和 .env
数据库：config.db
密钥：secrets/ 目录以及 .env。请妥善备份，勿公开。
日志：.local-run/backend.log 和 .local-run/frontend.log
电脑重启后需要重新执行启动命令。

编译：
  /opt/homebrew/bin/go build -o guanlan .
  cd web && npm ci && npm run build

这是较早的上游分支，npm 安装报告依赖漏洞；此部署只供本机访问。
