# 智能交易台 UI 规范

参考 ui-ux-pro-max 官方技能（https://github.com/nextlevelbuilder/ui-ux-pro-max-skill），采用翡翠绿与中性炭灰金融工作台布局。保留现有账户、策略、信号与交易流程。

- 基础色：背景 #0b1012，面板 #141d21，边框 #293a40，正文 #edf5f3，次要文字 #a5b8b8，主操作 #34d399。
- 状态色：盈利 #52d6a0，亏损 #ff8492；同时显示数字和文字，避免仅依靠颜色。
- 字体：系统中文字体，无外部字体请求；数值使用等宽数字。
- 页面：最大内容宽 1480px，桌面侧边距 32px，手机 20px；卡片圆角 16px。
- 交互：主操作突出、次操作描边；输入控件最小高 44px；可见键盘焦点，遵循减少动画设置。
- 配置弹窗：固定标题和操作区、中间内容滚动，手机字段单列；焦点限制在弹窗，Escape 关闭，关闭后恢复原焦点。保存中禁止关闭。
- 首页覆盖数据来自公开合约接口，加载和失败分别处理，不伪造市场数字。
- 视觉检查：1440px 桌面首页、登录注册、总览和帮助页；375px 配置弹窗、帮助、手机菜单、登录页。配置弹窗使用临时组件预览，不提交实际配置。
- 自动检查：TypeScript/Vite 构建，合约选择/信号配置/API 错误/配置弹窗测试共 8 项。

入口样式在 web/src/index.css。新增界面优先复用语义 CSS 变量和 desk-* 组件类。
