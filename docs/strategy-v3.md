# 策略 v3 数据与决策核验

本次解决雷达标签缺少结构依据、时区歧义、指标精度损失、未收盘4小时数据混入，以及下单盈亏比使用假定入场价的问题。未经回测或模拟收益验证，不能据此声称预测准确率或盈利能力提高。

## 数据口径

- 当前时间使用 RFC3339，提示词同时提供等价 UTC 时刻和信号实际年龄，避免把北京时间与 UTC 相减得到8小时。
- 雷达 `structure_15m` 提供此前20根已收盘K线的高低点、平均成交额、已收盘EMA20/50及最近8根已收盘OHLC和成交额。参考窗口不包含突破K线；最后一根成交额除以此前20根平均成交额得到放量倍数。不新增API请求，不把观察价位当成推荐止损或目标价。
- 4小时EMA、ATR及量能仅用已收盘数据；历史不足50根时明确缺失。3分钟最新指标明确标注可能包含未收盘K线，仅作辅助。
- EMA、MACD、ATR及序列使用12位有效数字，避免低价币被格式化成相同数值或0。

## 判断规则

保留已有3:1毛盈亏比、成本、仓位、杠杆、4小时明确反向趋势及美股时段条件。没有降低风险预算。

4小时中性或缺失时可依原规则评估15分钟完整结构；不得用MACD单独为负或均线微小差异直接断言强反向趋势。RSI极值、缺少回踩、OI缺失不单独否决满足突破形态的机会。

每个候选需给出主要否决条件及对应数值或缺失字段；被前置条件否决的后续检查应视为未评估。只有列出入场价、结构止损、结构目标及计算结果，才能声称盈亏比不足；无法确定结构时应报告无法计算，不虚构目标凑比例。

原解析校验把入场价固定为止损至止盈区间的20%位置，比例因此几乎恒为4:1。已移除这项假定；多空开仓均在执行前按最新取得的行情报价核验止盈止损方向与3:1毛盈亏比，拒绝非有限数值。报价检查不能保证实际成交价或止损成交价。
