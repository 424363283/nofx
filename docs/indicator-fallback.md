# 系统自主判断与AI复核 v2

每轮先独立计算系统计划，再把计划和行情提交AI复核。AI同向时保留系统风控参数；意见不同或重复时该开仓等待；AI漏掉的标的按系统计划执行。AI不能把系统wait改成开仓。已有持仓允许AI建议对应方向平仓；系统确认的反向破位退出不被AI hold取消。

AI调用失败（402、超时、限流等）或响应解析校验失败时，使用system_only。成功时hybrid。每次调用结束重新验证技术报告时效，过期不下单。模型内部重试策略未修改，超时期间仍可能等待。

## 行情与形态

使用已收盘15m EMA20/50与ATR判断上涨、下跌、震荡/过渡和高波动。15m不可用则明确降级到3m。3m负责入场触发：趋势突破、回踩再启动、MACD或RSI50交叉动量延续、区间假突破收回。逆势反转需要15m与3m都确认拒绝突破。

多空各自按趋势25、MACD10、RSI10、形态25、量能15、位置15计分。量比0.8至1.2仅记8分。必须有形态、方向分至少60、领先至少15；评分是规则强度，不是胜率。双周期反转也必须满足该门槛。高波动（主周期ATR/价格超过5%）不新增仓位。

止损取3m结构失效点加0.2ATR缓冲；目标取有效3m/15m/4h已观察区间中最近的前方结构位。无目标或空间不足等待。毛风险回报至少2，成本按报价0.20%估算后的净风险回报至少1.25。每轮按方向分差优先最多一笔新仓；最高2倍且不超过配置，风险预算0.25%。资金、候选池、开市时段、持仓限制和保护单仍由原执行层校验。

已有持仓在15m反向趋势、3m放量破位及MACD/RSI反向共同确认时退出，本轮不反手。否则保持交易所保护单。

## 记录与验证

决策记录分别保存system_analysis、ai_decisions和最终执行动作；system_only保存fallback_reason。页面呈现行情/周期、多空规则分、形态、参考价、止损目标、系统原因和AI意见。独立系统分析可能包含多个机会，最终只选一项；未执行不等于无信号。

验证包括多空、过期/无效数据、成本与结构拒绝、AI报错降级、冲突等待、AI不能独立开仓、同向保持系统风控、15m及高波动、已持仓反向退出。尚无历史回测收益结论，不能据此推断盈利能力。
