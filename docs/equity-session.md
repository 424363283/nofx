# 美股候选时段过滤

非美国股票常规交易时段，无持仓的美股/ETF候选在获取详细行情及分配AI候选名额前直接移除；已有持仓独立保留并继续分析、管理。雷达页面仍可展示市场观察结果，入池不等于本轮送入AI。若过滤后没有任何候选或持仓，本轮不调用模型，只记录跳过原因。

时段按 America/New_York 09:30（含）至16:00（不含）计算，自动处理夏令时；周末、NYSE节假日及提前至13:00收盘的日期另行处理。使用NYSE已公布的2026–2028日历，超出覆盖年份时禁止新增美股候选，持仓管理继续。此处是应用选定的股票标的常规时段策略，并非宣称币安永续合约只有这些时间能交易。临时停市等额外事件不在静态日历覆盖范围。

类别优先取币安合约元数据，不靠合约名猜测；雷达/原生信号已有类别时直接使用。手工候选缺少类别时查询同一公开合约元数据（带缓存）；非交易时段无法确认类别的新候选暂时跳过，持仓不受影响。执行新开仓前再次检查时段，分析期间收盘也禁止新增美股仓位，不拦截平仓和其他持仓管理动作。
