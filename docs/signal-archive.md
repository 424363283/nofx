# 信号档案与效果追踪

入口 `/signals`，只读 API `/api/market/radar/archive`，由独立雷达进程提供。Vite 已有 `/api/market/radar` 前缀代理会同时代理档案；生产代理也须把该前缀交给雷达服务。

## 采集与持久化

数据保存在工作目录 `signal-archive.db`（SQLite WAL），可用 `GUANLAN_ARCHIVE_DB` 设置持久化路径。备份应使用 SQLite 在线备份接口，或停机后连同 WAL 一致备份，不能只复制一个正在写入的主文件。重启不会清空记录。不是用户交易记录，不存密钥。

只在成功扫描后捕获有效异动；保存整个 RadarItem 快照、首次记录时间及规则版本 radar-v1。去重键为版本、合约、信号K线时间、方向和排序后的信号种类/方向集合。同一K线出现新的证据组合会产生另一条记录，因此样本并非独立。所有方向均保留，不只保留成功信号。部署前及停机期间的遗漏不补造。

## 观察口径

以记录时获得的最新报价作为参考价，保存其报价时间。参考报价超过5分钟或明显来自未来时不记录。

15、60、240分钟任务持久化，首次采集必须等到目标时刻后的完整分钟结束。读取从记录后的下一个整分钟开始、到目标向上取整分钟之前的1m K线；分别需要15、60、240根。区间完整且连续才完成。终点比精确目标最多晚不到一分钟；首个不完整分钟不计极值。绝不以请求时当前价格代替历史终点。

价格涨跌 = (终点价/参考价 - 1) × 100。偏多方向收益等于价格涨跌，偏空取相反数。方向不明/多空冲突只保留价格涨跌；方向收益与极值为空。

有利/不利波动用完整分钟的高低价相对参考价计算，并纳入零基线。是无杠杆报价区间，不是账户回撤或可执行盈亏。此处的方向观察不包含止损/止盈；独立的固定规则模拟见下节。

后台每分钟最多解析32个到期任务，单轮预算50秒。HTTP错误、缺少/错序K线、非有限数值、异常价格结构不会写入完成结果；5分钟后重试，重启后也会继续。UI区分 pending（待观察）、unavailable（待补齐）、complete（已完成）。已到期但排队中的任务仍为待观察。

## 统计

分页30条，支持合约搜索、资产类别与方向筛选；统计跨当前筛选全部记录，不局限当前页。各周期仅完成的偏多/偏空样本计入方向符合率；严格大于零算符合，零收益不算。均值为无杠杆方向毛收益。

成本情景默认0.20%，只是用户可修改的往返手续费/滑点预算，平均毛收益减该值并非真实净收益，未包含实际资金费、成交约束或杠杆。当前没有独立样本置信区间、价格路径图或实际成交关联；相似组分析与固定规则模拟见下节。这些应在积累样本和完善数据后另行实现。

雷达规则实质变化时应提升版本号，再分版本比较。禁止将旧数据重写为新规则结果。

## 相似信号证据与固定规则模拟（paper-v1）

新增只读 API `/api/market/radar/archive/{id}/research`。相似组严格匹配资产类别、方向、雷达版本、排序后的信号种类及方向集合（不匹配数值强度，不局限同一合约）。只查原信号之前的档案，并要求观察结果/模拟结果在原信号记录前已完成且保存。未记录完成时间的旧结果不计入这一历史视角，避免把事后补齐数据作为当时已知信息。30 条只是界面上的最低样本提醒，不是显著性检验或可交易认证。

新增 `paper_trials` 持久化固定规则实验。仅新捕获的档案参与，不对启用前的历史档案重做模拟。每次捕获时即确定参与或跳过，规则版本固定：

- 明确偏多或偏空；报价时间不得晚于记录时间、不得陈旧超过90秒；24h USDT成交额至少500万，否则保存跳过原因。
- 同一合约在固定60分钟实验窗口内（不分多空）最多一个实验，其他信号保留档案但跳过模拟。即使前一实验可能提前止盈，也不缩短去重窗口。
- 下一完整分钟开盘价模拟入场，每侧施加0.02%不利滑点。相对滑点后的入场价，止损1%、止盈2%，最长60根1m K线。完整60分钟行情到齐后才结算；不是实时虚拟持仓或交易所订单。
- 按分钟顺序检查开盘跳空和区间触价；止损跳空使用开盘价，止盈跳空不提供优于目标价的改善；同根K线同时触价时止损优先并标注歧义。退出再施加不利滑点。
- 滑点后收益以初始名义金额为分母，多空方向相反；模拟手续费为每侧0.04%乘各自成交名义金额，退出金额随价格变化。扣费后收益未计资金费、杠杆、真实点差、市场深度和成交失败；不模拟本金、保证金或强平。不同合约实验可以重叠，均值与样本盈利比例不是账户收益、回撤或下一笔胜率。
- 参数是验证流程用的固定假设，不是已优化或已证明盈利的策略。改规则必须新增版本及对应计算分支，不能用新参数重算旧版本待处理任务。

模拟后台每分钟最多16项，独立40秒预算；缺失、错序、非法OHLC、HTTP失败保留 `unavailable`，5分钟后重试，未结算不计入分母。原始15m/1h/4h方向观察仍独立保留，其可编辑成本情景不影响固定模拟规则。`paper_stats` 使用与列表相同筛选；旧档案没有模拟，不计入实验总数。新记录的规则跳过、待结算与数据缺失均展示。

无交易员管理、账户密钥或下单接口依赖。升级只需重启只读市场雷达进程，不重启实盘后端。未来仍需跨时段验证、资金费和成交模型、组合风险以及测试网订单验证，再单独评估接入实盘。
