# 主动择机策略 v4

## 为什么调整

2026-11-09切换technical-v1后，检查最近35份决策记录，共136个wait、没有开仓建议。抽样理由集中于：4小时方向与15分钟反向被一票否决；只允许放量突破和回踩再启动；部分3分钟缓存过期。此样本只用于定位规则堵点，不能证明被过滤机会事后会盈利。

## 新行为

- 默认模板允许四类独立入场：A顺势突破、B回踩再启动、C已确认局部反转、D动量延续。只需一类符合，不叠加四套门槛。
- A量比从1.5降至1.2；B允许量比0.8或明确的缩量回踩后量能恢复；C量比0.8，D量比1.0。量比统一同周期成交额/此前20根均额。
- 4小时用于背景。与4小时方向相反只可走C类：完整15分钟结构、两类确认依据，风险预算0.25%。不能仅凭MACD交叉、背离或缩量猜反转。
- D允许在趋势内使用MACD/RSI触发或重新站上/跌破EMA20，不再要求每次刷新20根极值。
- AI自报confidence不再有建议75分门槛，也不是胜率。
- 毛盈亏比执行下限改为2:1；增加明确的成本后执行校验：(潜在收益−报价×0.002)/(止损距离+报价×0.002)≥1.25。两项均需通过，采用执行前报价及规范后的止盈止损价格。decision/entry_policy.go为共享常量，资金定额沿用相同成本预算。
- 仍保留0.25%/0.5%风险预算、最多3仓、最高3倍杠杆、总保证金30%、最低金额及保护单失败处理。每轮最多1个新开仓仍是默认提示词要求，并非本次新增的后台批次强制限制。

## 过期行情

market.Get在使用3m/4h流缓存前检查最近已收盘时间；超过一个周期加5秒时，通过公开REST补取100根，10秒超时。新鲜缓存不增加请求。补取失败或仍过期时不将旧数据送给AI。补取结果供当前轮次使用，不写回WebSocket缓存，避免与推送并发覆盖；每次行情读取每周期至多补取一次，未来轮次若缓存仍未恢复会重试。原技术分析仍校验连续性、OHLC、数值及历史长度。

## 验证

`go test ./market ./decision ./trader ./signals ./archive ./api`

新增用例覆盖多空2:1可通过、低于2:1拒绝、毛比例达标但成本不足拒绝、缓存新鲜不请求、过期恢复、失败与空结果不使用旧数据，以及完整默认提示词不再含3:1或旧周期否决冲突。

这次调整扩大可评估机会，可能增加交易及亏损频率，不保证每天有单，也未通过回测证明收益改善。禁止为满足交易次数虚构结构目标或跳过资金和保护单检查。
