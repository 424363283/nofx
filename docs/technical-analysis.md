# 多指标与形态分析 technical-v1

交易后端复用现有3分钟和4小时K线，在 market.Get 中计算确定性证据，由 market.Format 进入每个候选与持仓的模型输入。决策页展开“输入提示词”可查看原始数值、时间和命中形态。附加系统规则对默认与自定义提示词均生效，要求模型在 reasoning 中说明支持、冲突与缺失证据。仍由AI综合判断，执行层负责原有风险校验；没有引入指标自动下单模式。

## 数据约束

仅使用已收盘、连续、合法且未过期的K线，至少60根。最后收盘距当前不得超过一个周期加5秒。历史不足、断档、非法价格或非有限值显示“不可评估”，不会制造零指标。新分析无需额外行情请求，不修改雷达的 radar-v1 规则、候选池和历史实验口径。15分钟雷达证据仍独立提供，不能与3分钟事件混为一谈。

## 明确规则

- MACD：EMA12−EMA26为DIF，以前9个有效DIF的SMA初始化EMA9信号线DEA；柱值为2×(DIF−DEA)。仅最近两根已收盘发生交叉才标记金叉或死叉。旧 current_macd 字段保留DIF含义，新增提示明确区别。
- RSI14：Wilder平滑；70/30超买超卖，识别回到区间和穿越50。完全横盘且无涨跌时返回50，不再错误返回100。
- 背离：最近60根内，价格高低点左右各2根严格确认；比较最后两个同类枢轴，间隔至少5根，最新枢轴距当前不超过10根。价格新高/低需超过0.1%；RSI需反向至少3点，DIF需反向变化。提供两次枢轴时间、价格、指标和年龄。仅识别常规顶底背离，不声明隐性背离；确认必然延迟。
- 量价：最新成交额/此前20根均额；≥2为放量，≤0.7为缩量。高位/低位按收盘在此前20根高低区间顶部/底部20%及区间外计算。放量且收盘变化不超过0.25ATR14提示滞涨/滞跌。均额为0不计算量比。
- 结构：收盘突破此前20根高低点；影线越界而收盘回到区间为假突破/跌破候选，非反转确认。
- 蜡烛：实体吞没；实体≤全幅10%的十字星；主影线≥全幅60%、反向影线≤20%、实体≤30%的长影线。
- 补充提供EMA20/50、ATR14、前根DIF/DEA/RSI、区间高低点及最新OHLC，供核验。不同周期独立计算。

阈值是当前明确实现的启发式规则，尚未针对收益优化。高位缩量不等于出货，背离不保证反转，超买不直接做空，超卖不直接做多。相关指标不能当作独立概率证据叠加；不改变既有杠杆、资金、盈亏比和保护单要求。

公式参考：[Fidelity MACD](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)、[Fidelity RSI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/RSI)。形态阈值与背离枢轴选择为本项目规则。

## 验证与生效

测试覆盖MACD数值与真实交叉、横盘RSI、未收盘排除、错误/陈旧/断档数据、确认枢轴背离、量价与蜡烛形态，以及模型输入集成。运行 `go test ./market ./decision ./trader ./signals ./archive ./api`。

修改源码需重新编译并切换交易后端才生效。待切换构建 `.local-run/guanlan-technical-v1` 不会自动启动或替换正在运行的程序。此次未修改前端、未重新启动交易员、未发送实盘订单；指标效果尚未通过回测或实盘验证。
