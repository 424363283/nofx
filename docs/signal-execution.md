# 行情信号与资金执行分离

AI分析行情、趋势、已收盘触发、量能、结构止盈止损和价格盈亏比；资金不足不再是跳过分析或wait的理由。模型输入不展示账户净值、可用余额及资产变化百分比，不编造参考本金；现有持仓仍供管理分析。内部决策日志继续保留真实账户快照，页面资产展示不受影响。

合格信号输出open_long/open_short、方向、杠杆、止损、止盈及依据。position_size_usd=0、risk_usd=0表示由执行层定额，非无效信号；risk_budget_pct支持0.25或0.5，缺省0.25。解析只校验信号结构与参数，不因净值为0拒绝完整开仓建议。

执行层刷新真实资金和持仓，按止损距离加0.20%成本预算反推名义金额，并限制为单笔风险预算、单币不超过净值、保证金总占用不超过30%、可用余额保留20%及最多3个现有持仓；杠杆上限3倍。明确的正数建议金额只可下调，不会为凑最低金额提高仓位。低于系统最低金额（BTC/ETH 60 USDT，其他12 USDT）时失败，交易所还会核验自己的过滤规则。

资金为0、可用余额不足或风险预算不够时，动作仍是原来的开仓信号，success=false并注明“开仓失败：资金不足”等原因；不改写为wait，不设置保护单异常暂停标记，不中止后续分析轮次。账户接口报错或资金字段缺失时明确报数据错误，不伪造0余额。只有实际成交才进入已实现交易历史；失败建议保留在决策记录。

时段过滤、止损止盈保护失败后的新开仓暂停、已有持仓管理等其他限制保持生效。资金通过也不保证成交或盈利，实际订单及保护单仍需交易所确认。

验证覆盖零净值完整信号解析、输入无资金门槛、资金不足后的信号保留及后续轮次恢复、名义金额/保证金/风险预算/最低金额限制。未主动下实盘测试单。
